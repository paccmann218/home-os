HOUSE, AWAKE (version 2)
Made with Crayon - https://app.usecrayon.ai

PLAY
  Unzip this folder and double-click index.html. It opens in your web browser.
  An internet connection is needed: the game loads its 3D library and fonts from public CDNs.

PUT IT ONLINE
  Upload index.html to any static web host. On itch.io: create a new project, set
  "Kind of project" to HTML, upload this ZIP and tick "This file will be played in the browser".

FILES
  index.html     the whole game
  metadata.json  name, version and engine versions
  LICENSE.txt    who owns what, and the open-source libraries the game loads
